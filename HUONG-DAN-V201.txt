V201 - DEDUPLICATED MIGRATION

Lỗi đã xác định:
warehouses: ON CONFLICT DO UPDATE command cannot affect row a second time

Nguyên nhân:
Trong cùng một câu lệnh upsert có 2+ record cùng conflict key.
PostgreSQL không cho một row bị UPDATE hai lần trong cùng statement.

V201:
- Deduplicate trước toàn bộ payload.
- warehouses: theo id
- ingredients: theo id
- suppliers: theo id
- products: theo id
- inventory: theo warehouse_id + ingredient_id
- recipe_items: theo id
- prepared_ingredient_items: theo id
- stock_transactions: theo id
- ưu tiên record có updated_at/created_at mới hơn
- nếu thời gian bằng nhau thì ưu tiên record xuất hiện sau
- tính lại tổng migration sau dedup
- hiển thị số dòng trùng đã gộp

Không cần SQL mới nếu SQL V200 đã chạy thành công.

Cách dùng:
1. Deploy V201 lên thiết bị có dữ liệu đầy đủ nhất.
2. Cài đặt -> Đồng bộ -> Batch migrate.
3. Xem dòng "Đã gộp N dòng trùng".
4. Nếu phase khác bị lỗi, gửi ảnh phase + lỗi.
