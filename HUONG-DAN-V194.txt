V194 - SYNC DIAGNOSTICS

V194 bổ sung nút "Chạy kiểm tra" trong phần Đồng bộ.

Các kiểm tra:
- Cloud Online
- Database SELECT
- Canonical State
- RPC Sales V190
- RPC Import V191
- RPC Export V192
- RPC Stocktake V192
- RPC Canonical CAS
- Storage Upload/Read
- Cloud Pull
- Pending Retry
- Local/Canonical Merge
- Final Verification Pull
- Pending = 0

Diagnostics có tạo một object test nhỏ trong Storage, đọc lại rồi xóa.
Không tạo phiếu bán/nhập/xuất/kiểm kê giả.

Cách dùng:
1. Deploy V194 lên tất cả thiết bị.
2. Cài đặt -> Đồng bộ dữ liệu -> Chạy kiểm tra.
3. Chờ bảng PASS/FAIL.
4. Nếu có FAIL, chụp màn hình phần Diagnostics để xác định chính xác lớp lỗi.

Không cần SQL mới nếu Full Update V192 đã chạy thành công.
