V199 - BATCH MIGRATION

V198 có thể đứng ở 20% / 0 record vì gửi từng record riêng.
V199:
- gom dữ liệu theo batch 150 record
- hiển thị phase/table đang migrate
- hiển thị done/total
- timeout 30 giây mỗi batch
- lỗi table nào sẽ hiển thị rõ table đó
- không remap local trước khi tất cả Cloud writes hoàn tất
- sau migrate tự pull Cloud và kiểm tra coverage

Cách dùng:
1. Deploy V199 lên thiết bị có dữ liệu đầy đủ nhất.
2. Cài đặt -> Đồng bộ -> Batch migrate.
3. Theo dõi thanh Migration riêng.
4. Nếu dừng, gửi ảnh có tên phase + lỗi.
